Output 1: Project Development Timeline
Project Name
Scan2Sheet Local
One-Line Goal
Build a free, local-first OCR app that scans Indian invoices, receipts, ledgers, or passbook pages and converts them into verified CSV/Excel-ready accounting data.
What We Are Making
We are making a simple document-to-spreadsheet pipeline.
The user uploads or scans a document image. The system preprocesses the image, runs local OCR, extracts useful fields, validates the extracted data, lets the user review/edit the result, and exports clean data as CSV.
This is not a generic OCR app. The focus is:
Indian accounting documents → structured data → validation → export

Hard Constraints
No paid APIs.
No Chinese LLMs.
No Chinese OCR models.
No Chinese cloud AI services.
Prefer local/free/open-source tools.
Avoid unclear model provenance.
MVP must work offline or mostly offline after setup.
Allowed Core Stack
Frontend: React / Vite / PWA
Backend: Python FastAPI
OCR: Tesseract OCR
Image processing: OpenCV
Data handling: pandas / Python CSV
Extraction: regex + rules
Optional simple ML: scikit-learn classifier
Export: CSV first, XLSX later
MVP Scope
Support two document types:
GST Invoice / Bill
Extract:
Vendor/customer name if visible

Hour 1-3: Backend Skeleton

Save temporarily.

Run OCR.
Return structured JSON.
Expected response shape:

  "document_type": "invoice",
  "raw_text": "...",
  "fields": {
    "gstin": "...",
    "invoice_number": "...",
    "date": "...",
    "total": "..."
  },
  "rows": [],
  "warnings": []
}

Upload endpoint accepts image.

Hour 3-5: OCR Pipeline
Implement local OCR.
Steps:
Load uploaded image.
Convert to grayscale.
Apply thresholding.
Optionally denoise.
Run Tesseract.
Return raw text.
Pipeline:
image → OpenCV preprocessing → Tesseract → raw text
Deliverable:
Upload image and get OCR text back.
Raw OCR text visible in API response.

Hour 7-9: Ledger / Passbook Extraction
Implement simple row parser.
Detect lines containing:
date
text description
amount-like values
Supported date examples:
12/04/2025
12-04-2025
12 Apr 2025
Expected row:
{
  "date": "12/04/2025",
  "description": "UPI CREDIT FROM RAHUL",
  "debit": "",
  "credit": "5000",
  "balance": "21500"
}
Deliverable:
One ledger/passbook image produces transaction rows.
Hour 9-11: Validation Engine
Add validation rules.
Invoice validations:
Missing GSTIN.
Invalid GSTIN format.
Missing invoice date.
Missing total.
Tax math mismatch:
taxable + cgst + sgst + igst ≈ total
Ledger validations:
Missing date.
Both debit and credit filled.
Neither debit nor credit filled.
Invalid amount format.
Running balance mismatch if enough rows are available.
Warning format:
{
  "level": "warning",
  "field": "total",
  "message": "Total does not match taxable amount plus tax."
}
Deliverable:
App can show “AI is useful because it catches mistakes.”

Definition of Done for MVP
The project is done when:
A user can upload an image.
OCR runs locally.
Extracted text is visible.
At least one invoice is parsed into fields.
At least one ledger/passbook page is parsed into rows.
Validation warnings appear.
User can edit extracted data.
User can export CSV.
No paid or Chinese AI dependency is used in the core pipeline.
